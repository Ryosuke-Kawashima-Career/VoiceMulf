# Build and Sell Voice agents

## Problem

At this Build in Public session, we take a real business use case and turn it into a working voice agent live on stage, on Murf AI's Falcon 2 TTS API. You build along with us. A developer from the Murf team will be in the room to help with keys, setup and integration.

​What we'll cover:

- ​A live build from a real business use case to a working Falcon 2 voice agent
​- Which businesses are actually paying for voice agents right now
​- What to build for them, including multilingual and Indian-language agents
​- How to price it and pitch it to your first client
